# NEXCORE — C&D Waste Management Digital Marketplace (Android)

**Tagline:** *Construction Waste. Renewed Value.*

## Direct APK Download (`shafffff699/Nextcore-apk`)

Once this project is synced/pushed to **`shafffff699/Nextcore-apk`**, GitHub Actions automatically compiles the Android APK and publishes it to two places:

1. **GitHub Releases (Direct `.apk` Download):**
   - Go to: [`https://github.com/shafffff699/Nextcore-apk/releases`](https://github.com/shafffff699/Nextcore-apk/releases)
   - Click **`NEXCORE-debug.apk`** under the latest release to download directly to your phone or computer.

2. **GitHub Actions Build Artifacts:**
   - Go to: [`https://github.com/shafffff699/Nextcore-apk/actions`](https://github.com/shafffff699/Nextcore-apk/actions)
   - Select the latest **Build & Release NEXCORE APK** workflow run and download **`NEXCORE-debug-apk`** at the bottom under **Artifacts**.

---

## Downloading the APK Directly from AI Studio

You can also download the pre-built APK directly from AI Studio without leaving the browser:

1. **Via the AI Studio Settings / Export Menu:**
   - Click the **Settings (gear icon)** or **Download / Export** button in the top-right corner of AI Studio and select **Download APK** (or **Export ZIP**).
2. **Via the Code Editor File Explorer:**
   - Open the **Code / File Explorer** panel in AI Studio.
   - Locate **`.build-outputs/app-debug.apk`**, right-click it, and select **Download**.
